# Výukové materiály

Jednoduchý statický web pro výuku informatiky v pro studenty ve věku 15–22 let.

## Co obsahuje

- úvodní stránku s přehledem témat,
- levý sidebar s navigací,
- stránku lekce se základním výkladem,
- informační boxy a interaktivní kvíz,
- responzivní design pro desktop i mobil.

## Spuštění

Stačí otevřít soubor `index.html` v prohlížeči nebo web nasadit na GitHub Pages.

## Struktura projektu

- `index.html` – úvodní stránka
- `lesson.html` – lekce s výkladem a kvízem
- `css/style.css` – stylování
- `js/main.js` – interaktivita
- `images/` – ilustrace
